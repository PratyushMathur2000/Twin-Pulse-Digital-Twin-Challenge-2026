Biophysical ODE Engine

  • • Numerical Solver: 4th-order Runge-Kutta (RK4) with adaptive step size (Δt = 10 ms).
  • • Coupling Matrices: Symmetric feedback between autonomic vagal tone, hepatic gluconeogenesis, and renal vascular resistance.
  • • Calibration: Individualized patient baseline tuning with parameter estimation via Bayesian MCMC.
Engine: JS / WebAssembly Core 100 Hz Execution
